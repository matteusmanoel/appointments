**Explicação do prompt:**

### **1\. Por que este prompt é "Completo" (Análise de Engenharia de Prompt)**

O que torna esse prompt robusto não é o tamanho, mas a **governança de comportamento**. Você cercou a IA de todos os lados para evitar alucinações.

* **Metodologia SPIN Selling Embutida:** Você não pediu apenas para "vender". Você estruturou o *raciocínio* da venda (Situação, Problema, Implicação, Necessidade). Isso impede que a IA seja "vendedora chata" e a força a ser consultiva.  
* **Estado da Conversa (State Machine):** Ao definir IDs de mensagens (01 a 15\) e "Etapas do Funil", você transformou o chat em uma **Máquina de Estados**. A IA sabe exatamente onde está. Ela não vai oferecer a reunião na "Mensagem 2" porque o prompt proíbe essa quebra de sequência lógica.  
* **Guardrails (Regras de Proteção) Rígidos:** As regras negativas são vitais.  
  * *Ex:* "NUNCA use 'amanhã'", "NUNCA invente horários".  
  * Isso resolve o problema clássico de IAs que perdem a noção temporal. Ao forçar o formato `(DD/MM)`, você elimina a ambiguidade para o usuário e para o sistema.  
* **Gatilhos de Execução (Trigger-Action):** A seção "GATILHOS PARA..." funciona como um `if/else` lógico. Você tirou a subjetividade da IA.  
  * *Se* lead diz "cancelar" \-\> *Então* execute `deletar_evento`.  
  * Isso garante consistência operacional, independente de como o usuário escreva.

### **2\. Por que o JSON é OBRIGATÓRIO no n8n (A "Cola" da Automação)**

Aqui está o "pulo do gato" para quem usa n8n. Se você pedisse resposta em texto comum, teria um pesadelo para processar a saída. O JSON é o que torna sua automação **escalável**.

#### **A. Estrutura de Dados Previsível (Parsability)**

O n8n precisa de dados estruturados para passar de um nó para outro.

* **Sem JSON:** O n8n receberia um bloco de texto. Você teria que usar Regex ou outra IA para tentar adivinhar o que é a resposta pro cliente e o que é comando interno.  
* **Com JSON:** Você usa um nó `JSON Parse` e imediatamente tem variáveis separadas:  
  * `$json.mensagens[0].conteudo`: Vai direto para a API do WhatsApp.  
  * `$json.toolsUsadas`: Vai para um nó "Switch" ou "If" para decidir se chama o Google Calendar.  
  * `$json.etapaFunil`: Vai para seu CRM ou planilha para atualizar o status do lead.

#### **B. Separação de "Pensamento" e "Fala"**

No seu JSON, você tem campos distintos. Isso permite que a IA "pense" (decida usar uma tool) sem "falar" isso para o cliente.

* O campo `motivo` dentro da tool é genial. Ele força a IA a fazer um "Chain of Thought" (cadeia de pensamento), justificando a ação. Isso aumenta drasticamente a precisão da escolha da ferramenta.

#### **C. Tratamento de Erros**

Se a IA alucinar no formato, o JSON quebra. No n8n, isso gera um erro no nó `Parse`. Você pode criar uma rota de erro (Error Trigger) que tenta corrigir o JSON automaticamente ou te avisa. Se fosse texto livre, a IA poderia enviar uma mensagem errada para o cliente e o n8n nem perceberia.

O que você criou aqui é o cérebro de um agente autônomo.

1. **Input:** Mensagem do WhatsApp entra no n8n.
