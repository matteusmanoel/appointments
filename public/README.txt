NavalhIA — assets para o site

Coloque os arquivos na pasta public/ do site.

HTML no <head>:
<link rel="icon" href="/favicon.ico" sizes="any">
<link rel="icon" type="image/png" sizes="32x32" href="/favicon-32x32.png">
<link rel="apple-touch-icon" href="/apple-touch-icon.png">
<link rel="manifest" href="/site.webmanifest">
<meta property="og:image" content="https://SEU-DOMINIO/og-image.png">
<meta name="twitter:card" content="summary_large_image">
<meta name="twitter:image" content="https://SEU-DOMINIO/og-image.png">

Substitua SEU-DOMINIO pela URL publicada. og-image.png: 1200 x 630. social-square.png: 1080 x 1080.
